Open5GS, UERANSIM, Raspberry Pi 5, FastAPI, TensorFlow MobileNetV2, and AWS EC2.

The project includes:

- an end-to-end simulated 5G SA data path;
- AI inference at the edge and in the AWS cloud;
- raw benchmark data, statistical analysis, and charts;
- paired LAN and 5G health measurements;
- sanitized configurations and documented methodological limitations.
